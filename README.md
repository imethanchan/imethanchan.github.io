# Ethan Chan - Resume & Art Portfolio

Live website: https://imethanchan.github.io/

Public contact: pokmanchan@gmail.com

## Updating the website
Use **Owner sign in** in the website footer to open the secure studio. The studio remains hosted on the existing backend; only the public pages are hosted on GitHub Pages.

Saved CV text, slogans, layout settings, background images and uploaded artwork are loaded from the public content API when a page opens, when its tab returns to focus, and periodically while visible.

## Hosting
- GitHub Pages publishes the main branch, repository root, over HTTPS.
- index.html is the resume homepage.
- portfolio.html is the dark art portfolio.
- cv.pdf is the downloadable CV.
- Only public-facing files are included here. Private configuration, credentials and original CV files are excluded.
- If the live-content service is temporarily unavailable, the site shows its last published snapshot with a notice.

The secure studio and file storage continue to use the existing Sites backend.

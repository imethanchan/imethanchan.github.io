# Ethan Chan Resume and Art Portfolio

Live website: https://imethanchan.github.io/

Public contact: pokmanchan726@gmail.com

The complete website, editable content, CV, gallery previews and original photographs are stored in this GitHub repository and served by GitHub Pages. The website has no external content server, account service or database dependency.

## Editing and uploads

Read [EDITING.md](EDITING.md) for step-by-step instructions.

- [Edit website text and layout](https://github.com/imethanchan/imethanchan.github.io/blob/main/content.json)
- [Edit artwork titles, categories and descriptions](https://github.com/imethanchan/imethanchan.github.io/blob/main/artworks.json)
- [Upload photographs or replace cv.pdf](https://github.com/imethanchan/imethanchan.github.io/upload/main)

Publishing requires repository write access through GitHub. Public viewing does not grant editing access.

## Files

`original-*` files preserve the migrated full-resolution uploads. `preview-*` files are smaller gallery images. `migration-inventory.json` records the size and SHA-256 checksum of every migrated original. The editable source and reproducible build script are included alongside the published HTML, CSS and JavaScript.
